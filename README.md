# Awacak

Application d'observation pour les enfants de 0 à 5 ans en halte-garderie : repères fonctionnels par domaine (programme éducatif du Québec), roue de la médecine, prochains pas, notes dictées et portrait périodique.

Les données restent sur l'appareil (IndexedDB, base « awacak-db », distincte du carnet nature). Faites des sauvegardes régulières.

Mise en ligne : déposer tous les fichiers (index.html, reperes.js, manifest.webmanifest, sw.js, dossier img) à la racine d'un dépôt GitHub, puis activer GitHub Pages.

## Fils de progression (v5)
Le fichier `fils.js` contient les progressions (ciseaux, crayon, ballon, sauts, s'habiller, transitions, jouer avec les autres…), inspirées des fiches d'habiletés de l'équipe. Pour chaque fil : l'intérêt de l'enfant en premier, les étapes (Commence, En voie, Acquis), puis où il l'utilise ailleurs (de lui-même, matériaux, contextes). L'équipe peut modifier ou ajouter des fils dans ce fichier.
